RUN THE MODEL

Day-ahead prices for DK2 are published once a day by Energinet, and tomorrow usually tracks today. This page loads the recent hourly prices itself and calls the deployed dk2-elspot-forecast workflow, which runs Mistral's Timestral time-series model on them (no retraining — the history is the context) with the weather forecast (wind, temperature, solar radiation from Open-Meteo) as known-future covariates, since weather drives both generation and prices. Your API key is only stored in this browser and sent to api.mistral.ai.
