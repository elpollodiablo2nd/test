ELSPOT

Timestral 1.0 · Denmark

ABOUT · HOW IT WORKS · SOURCES

elspot forecasts day-ahead electricity prices in Denmark — pick DK2 · EAST (default) or DK1 · WEST in the RUN card (remembered). Timestral runs on-device via ONNX: no API key, no server.

What to push: 1) prices load automatically — live from Energinet with retries/Retry-After; if that fails on this network (common on shared mobile IPs, remembered for 1h), it falls back to the remote Pages snapshot (refreshed every 30 min by a GitHub Actions job, which itself falls back to Nord Pool), then the local cache (freshest wins), then the snapshot bundled in the APK. The banner always names the source; LOAD PRICES forces a live retry; 2) optionally pick the model (5M bundled in the APK; 28M downloaded once from Pages, then stored in the app cache — it survives app restarts and switching models never re-downloads; 123M/209M disabled, too big on-device), the horizon (24/48/72h) and the EV window (4/6/8h); 3) press RUN TIMESTRAL — the ONNX-exported Timestral runs on this device in ~1–5 s.

What to expect: the app fetches weather (Open-Meteo at the zone's location — Copenhagen for DK2, Esbjerg for DK1) and runs the model with wind/temp/solar covariates plus hour-of-day/weekday encodings. The chart shows from the current hour: published day-ahead prices ahead of now (green), the cream dashed lag-1 baseline (tomorrow ≈ today), the orange dashed median forecast with the red q10–q90 band, the NOW line, and the green shaded EV charge window. The x-axis shows time of day plus weekday + date (DD/MM) at each day boundary, with an adaptive step (1h…96h depending on the window). The HUD shows the cheapest hour and the EV window; the grid lists every hour from now. Prices are in kr/kWh (source data is DKK/MWh ÷ 1000); with INCL. FEES+VAT ticked they include the mandatory fees — Energinet transmission+system tariff + elafgift (national) and the DSO Nettarif C (N1 for DK2, TREFOR for DK1; low at night, peak 17–21) — fetched live from DatahubPricelist with all ValidFrom/ValidTo windows, so seasonal/quarterly tariff changes are automatic, plus 25% VAT: what you actually pay per kWh.

Prices: Energi Data Service — DayAheadPrices (DK1/DK2), day-ahead, published daily ~13:00 CET. Fees: DatahubPricelist (Energinet GLN 5790000432752; N1 5790001089030 for DK2; TREFOR 5790000392261 for DK1) + 25% VAT. Model: Mistral Timestral 1.0, ONNX export on-device in the Android app (elspot-dk2-android/; the dk2-elspot-forecast workflow in elspot-dk2-workflows/ remains available via API). Weather: Open-Meteo. Snapshots: refreshed every 30 min by the GitHub Actions workflow (Nord Pool data-portal fallback). Full docs: README.md.
