ABOUT · HOW IT WORKS · SOURCES

Prices load automatically (live → cache → bundled snapshot) — then press RUN TIMESTRAL: Timestral runs on-device via ONNX, no API key.

What to push: 1) prices load automatically from Energinet — with retries and Retry-After handling, then the cached copy, then a bundled snapshot, so the chart fills even when Energinet rate-limits (LOAD PRICES just retries); 2) optionally pick the Timestral checkpoint (5M bundled in the app, 28M downloaded once) and the horizon (24/48/72h — beyond 24h there is no published day-ahead price to check against and the confidence band widens); 3) press RUN TIMESTRAL — the ONNX-exported Timestral runs on this device, no API key.

What to expect: the page fetches the weather forecast (Open-Meteo), runs the ONNX-exported Timestral on this device (~1–5 s, the banner shows progress), and then shows the chart from the current hour: published day-ahead prices ahead of now, then the orange dashed median forecast with the red q10–q90 confidence band, and the green shaded EV charge window (start = cheapest EV 4/6/8h run). The hourly grid and HUD update too: backtest MAE of Timestral vs lag-1, cheapest hour, EV window. Prices are in kr/kWh (source data is DKK/MWh ÷ 1000); with INCL. FEES+VAT ticked they include the mandatory fees — Energinet transmission+system tariff, N1 Nettarif C (low at night, peak 17–21), electricity tax — plus 25% VAT, i.e. what you actually pay per kWh.

Prices: Energi Data Service — DayAheadPrices (DK2), day-ahead, published daily ~13:00 CET. Fees: DatahubPricelist (Energinet transmission+system tariff, N1 Nettarif C, elafgift) + 25% VAT. Model: Mistral Timestral 1.0, ONNX export running on-device in the Android app (elspot-dk2-android/; the dk2-elspot-forecast workflow in elspot-dk2-workflows/ remains available via API). Weather: Open-Meteo. Full docs: README.md.
